# ADN Servicios Informáticos

Sitio de [ADN Servicios Informáticos](https://www.adnpc.com.ar/), servicio técnico en Guaymallén, Mendoza.

Sitio estático (HTML, CSS y JS sin dependencias). Las animaciones 3D de la notebook y la impresora son secuencias de cuadros renderizados en Blender que avanzan con el scroll (`assets/seq/`), con las etiquetas ubicadas según `anchors.json`.

## Ver en local

```bash
python -m http.server 8765
```

y abrir http://localhost:8765
